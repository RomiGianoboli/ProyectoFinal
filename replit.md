# ProyectoFinal

## Overview
A simple web application serving a landing page. This project was imported from GitHub and set up to run on Replit.

## Project Structure
- `index.html` - Main landing page with styling
- `server.js` - Node.js HTTP server serving the static page
- `package.json` - Node.js project configuration

## Recent Changes
- **Nov 5, 2025**: Initial Replit setup
  - Created basic web server using Node.js
  - Added landing page with gradient design
  - Configured to run on port 5000 with host 0.0.0.0
  - Set up workflow and deployment configuration

## Technical Details
- **Language**: Node.js (JavaScript)
- **Port**: 5000
- **Host**: 0.0.0.0 (required for Replit preview)
- **Cache Control**: Disabled for development

## Running the Project
The project runs automatically via the configured workflow. The server serves a single-page application at the root URL.
